# settings

Cards of the Settings page.

1. `ServiceCard.tsx`: concurrency control and the resource meters.
2. `JobsControl.tsx`: slider and step buttons for the concurrent job cap, saved 300 ms after the last change.
3. `Meter.tsx`: a labelled meter bar.
4. `ModsCard.tsx`: PlaylistManager card: status, install with a confirm dialog, GitHub link.
5. `ModStatusView.tsx`: game version, installed and available versions, dependencies.
6. `GameFolder.tsx`: the game folder setting.
7. `CardHead.tsx`: icon tile and title shared by the cards.
