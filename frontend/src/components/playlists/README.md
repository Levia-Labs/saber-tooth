# playlists

The Playlists tab: local `.bplist` playlists built from library maps and job output.

1. `LpTable.tsx`: the playlists table, with sort and filter in the header and one row per playlist.
2. `LpEditor.tsx`: create or edit one playlist: details, cover, songs and the export settings (subfolder, sync URL).
3. `LpSongPicker.tsx`: add songs from the library, a finished job's output, or the latest generated or fixed maps.
