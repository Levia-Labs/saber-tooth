# beatsaver

The BeatSaver view, built on the library's table shell, columns, chips and tooltips.

1. `BsTable.tsx`, `BsHeader.tsx`, `BsRow.tsx`, `BsSkeletonRow.tsx`: the virtualised map table.
2. `BsFilterBodies.tsx`, `BsToolbar.tsx`, `PresetsBar.tsx`: filters in header popovers and the filter sheet, saved presets.
3. `SelectionBar.tsx`, `selection.ts`, `downloads.ts`: ticked maps, the download confirmation and per-map progress.
4. `BsResults.tsx`, `BsTabs.tsx`: toolbar, banners, list and footer shared by the maps and playlist pages.
5. `Preview.tsx`, `Box.tsx`: audio preview button and the labelled checkbox.
6. `PlaylistList.tsx`, `PlaylistTable.tsx`, `PlaylistHeader.tsx`, `PlaylistRow.tsx`, `PlaylistToolbar.tsx`, `PlaylistFilterBodies.tsx`: the playlist table with header filters, sorts, mobile bar and Download all.
