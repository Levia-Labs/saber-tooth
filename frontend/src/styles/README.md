# styles

Plain CSS with custom properties; no framework.

1. `tokens.css`: colours, type and row heights.
2. `base.css`: reset, app shell, buttons and inputs.
3. `library.css`: library bar, scroll region, sticky header and filter buttons.
4. `rows.css`: library rows, cover, skeletons and the responsive and mobile card layouts.
5. `chips.css`: status and level chips.
6. `overlays.css`: tooltip, popovers, checkboxes and the fullscreen filter sheet.
   `filters.css`: filter popover and sheet bodies (rows, lists that scroll, range inputs).
   `pill.css`: the pill switch (`.mode-switch`, `.pill`) shared by the section tabs, map tabs and crop length switch.
7. `beatsaver.css`: header mode switch, presets, selection bar and the BeatSaver table layouts.
   `barslot.css`: the toolbar slot at the right end of the BeatSaver title row.
8. `alerts.css`: alert variants and the visually hidden helper.
9. `preview.css`: the audio preview button and its progress ring.
10. `crop.css`: the crop panel and its NPS chart.
11. `vr.css`: the VR layout, active only under `[data-ui="vr"]`: 22 px text, 64 px targets, 16 px gaps, focus ring, one to three column grid, and the Library card and toggle layout.
12. `generate.css`: the generate card: "or" divider, audio drop zone, over and disabled states.
13. `vrmode.css`: the masthead layout switch (VR / Desktop toggle group, shown in both layouts).
