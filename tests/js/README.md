# tests/js

Node built-in test runner suite for the browser modules. Run with `npm run test:js` or `task st:js-test`.

1. `timeline.test.mjs`: pure geometry exports of [timeline.js](../../src/saber_tooth/web/timeline.js).
2. `retry.test.mjs`: polling retry policy.
3. `urlstate.test.mjs`: library query state encode, decode and API query building.
4. `router.test.mjs`: route matching and link interception.
5. `tooltip.test.mjs`: tooltip placement math.
6. `chips.test.mjs`: status chip labels and difficulty pips.
