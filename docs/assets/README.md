# docs/assets

Static image assets for the project docs. Both files are hand-written SVG.

1. `logo.svg`: the full saber-tooth wordmark logo (720 by 200), with glow filters.
2. `logo-mark.svg`: the mark alone, without the wordmark.

The web UI ships its own `favicon.svg` in [src/saber_tooth/web](../../src/saber_tooth/web/README.md). Back to [docs](../README.md).
